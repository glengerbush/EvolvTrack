# Start Fresh requires verified exhaustion and cleanup

Start Fresh is available only when the current device has no readable treatment data and the person confirms no other device or backup holds a Recoverable Copy; missing Recovery Code Acknowledgment never qualifies. After confirmation, EvolvTrack remains in an Encryption Transition until cloud plaintext changes, encrypted changes, and wrapped keys are verified absent, retrying after connectivity failures rather than completing into plain mode with orphaned or reappearing data.
